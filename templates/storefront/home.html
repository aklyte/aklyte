Need Help?

Frequently Asked Questions

Find answers to common questions about purchasing, payments and GitHub source-code delivery.

What do I receive after purchasing a project?
You receive access to the specific private GitHub repository associated with your purchased project, subject to successful payment and GitHub account connection.
How do I access my purchased source code?
Connect your GitHub account to AKLYTE. After successful payment, an invitation is sent to your connected GitHub account. Accept the invitation to access the repository.
Will I get access to all repositories in the organization?
No. Repository access is provided for the specific project you purchased. Other AKLYTE organization repositories are not included in that purchase.
Do I need a GitHub account?
Yes. You need a GitHub account connected to your AKLYTE customer account to receive private repository invitations. Create a GitHub account.
How can I download the project?
After accepting the GitHub repository invitation, you can clone the repository using Git or download the source code from GitHub.
Are installation instructions provided?
Installation instructions and documentation are provided where available on the individual product detail page.
What payment methods are supported?
Available payment methods are displayed during checkout through the integrated payment gateway.
What should I do if I do not receive my GitHub invitation?
Check your GitHub notifications and registered email address. You can also visit the GitHub Access section in your AKLYTE account or contact customer support.
How can I contact AKLYTE support?
Sign in to your AKLYTE account and use the Help & Support section to submit a support request.
