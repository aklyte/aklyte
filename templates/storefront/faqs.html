Frequently Asked Questions

Answers to common questions about AKLYTE.

What is AKLYTE?
AKLYTE is a digital marketplace where customers can explore and purchase software projects and source code.
What do I receive after purchasing a project?
After a successful purchase, the marketplace creates a delivery record for the purchased project when repository details are configured. The customer can receive an invitation to the corresponding private GitHub repository. Available product documentation may also be provided.
Do I need a GitHub account?
Yes. You need a GitHub account connected to your AKLYTE account to receive repository access. Make sure you connect the GitHub account where you want to receive the invitation.
How do I receive the GitHub invitation?
After the purchase is successfully processed, AKLYTE sends an invitation to the connected GitHub account when repository delivery is configured. Check your GitHub notifications and the email associated with your GitHub account.
How do I clone a purchased project?
First accept the repository invitation on GitHub. Once your access is active, use the repository's Git clone URL in your terminal. For example: 
git clone https://github.com/OWNER/REPOSITORY.git
Replace OWNER and REPOSITORY with the repository details shown for your purchase.
Can I access every AKLYTE GitHub repository after one purchase?
No. Repository access is associated with the specific project purchased. It does not automatically grant access to other private repositories in the AKLYTE organization.
Where can I find installation instructions?
Check the product details and any documentation provided with your purchased project. Requirements and setup steps may differ between projects.
What should I do if I do not receive a GitHub invitation?
Confirm that the correct GitHub account is connected, then check your GitHub notifications and email. You can also check the GitHub access section in your AKLYTE account or contact support.
How can I contact AKLYTE?
Email aklyte200@gmail.com or visit the Contact Us page. Logged-in customers can also create a support ticket.
